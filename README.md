# Plots-for-Report-on-Ferromagnetism
Contains the LaTeX code for generating the plot used for the project report on Origin of Ferromagnetism submitted as a part of the course PHC-302. 

### 1. Bethe–Slater Curve
* **Citation:** White, R. M. (2007). *Quantum Theory of Magnetism*. Springer.

### 2. Spontaneous Magnetization vs. Temperature
* **Citation:** Stanley, H. E. (1971). *Introduction to Phase Transitions and Critical Phenomena*. Oxford University Press.

### 3. Bloch Domain Wall Schematic
* **Citation:** Coey, J. M. D. (2010). *Magnetism and Magnetic Materials*. Cambridge University Press.

### 4. Magnetic Hysteresis ($B-H$) Loop
* **Citation:** Kittel, C. (2005). *Introduction to Solid State Physics*. Wiley.
